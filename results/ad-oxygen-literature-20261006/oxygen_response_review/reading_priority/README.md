## 哪些支持能算独立

本次核对8篇机制关联原始研究的PubMed元数据/摘要，并补读C. difficile 2020相关Methods/Results。引用/作者/机构记录、原始DOI和短引均在26行关联表。**没有确认同一对象、相同关键条件下的严格独立重复；这不等于文献中不存在。**

- **FDP/SOR防御存在不同团队跨类群原始支持，仍标暂定边界**：P. furiosus 2012（[10.1073/pnas.1208605109](https://doi.org/10.1073/pnas.1208605109)，Adams/Georgia）SOR/FDP_A缺失的O2表型，与本批2024 C. difficile SOR和S. wolfei FDP_H形成不同对象的支持。2012目前仅摘要；不能据此宣称S. wolfei完整细胞已独立验证或所有AD古菌都依赖SOR。
- **不能把跨类群自动当不同团队**：C. difficile FDP/逆rbr 2020（[10.1128/mBio.01559-20](https://doi.org/10.1128/mBio.01559-20)）与S. wolfei FDP_H 2024共享Martins/Folgosa及ITQB团队。2020有酶学、染色体恢复和低氧生理证据，但不构成完全独立实验室复制。其质粒互补未成功而染色体恢复成功、H2O2体外活性未必有对应缺失表型，也限制了“有酶活即有同等生理作用”的说法；[原文位置](support_fulltext_excerpts.json)已保存。
- **低水平氧利用有不同团队跨类群支持**：A. muciniphila 2016与B. fragilis 2004（[10.1038/nature02285](https://doi.org/10.1038/nature02285)）支持某些bd系统的条件性氧利用。仍需全文核实，不能推广所有严格厌氧菌或直接证明AD原位呼吸。
- **互营保护的跟进并非独立团队**：2024脂肪酸共培养（[10.1016/j.biortech.2024.131829](https://doi.org/10.1016/j.biortech.2024.131829)）与R13862共享Duarte、Pereira、Stams、Cavaleiro。它提供更直接的±Pseudomonas/O2比较，但目前只读摘要、归为团队重叠的后续支持。2018甲烷氧化菌共培养是不同体系的支持性观察，不是同一中介机制复制。
- **PFOR损伤/修复有明确适用条件**：2001与2020 B. thetaiotaomicron研究共享Imlay，不能计独立验证；2001摘要与2020全文的修复性表述差异需对照旧全文，不能先判哪篇错误。不同团队Desulfovibrio 2008（[10.1021/bi7014713](https://doi.org/10.1021/bi7014713)）证明二硫键相关保护/可逆恢复，反对把所有PFOR写成同样易损且不可修复，但不直接推翻Bacteroides特定条件结果。
- **超氧损伤FeS的一般生化支持**：Flint等1993（[10.1016/S0021-9258(18)41538-4](https://doi.org/10.1016/S0021-9258(18)41538-4)）是另一团队的纯化酶/簇铁释放研究；包含非厌氧/哺乳动物酶，仅作一般生化背景，不能冒充直接厌氧群落O2证据。

关联材料中4篇早于2012年（1993/2001/2004/2008）已明确标基础/条件线索。这8篇只用于机制关联核验，未冒充新增一批已完成范围筛选的文献，因此当前17篇RIS没有自动混入这些未完成正式候选筛选的支持文献。

## 引用与期刊指标口径

分层先看对象/过程与直接证据，再看具体机制验证关联；不计算可由引用/JIF补偿科学缺陷的总分。引用与JIF供同层级辅助比较，不按这些指标机械强排不同机制。R07202虽有187次引用及2024 JIF12.4，仍因主要是功能潜力而列边界；S. wolfei FDP_H虽仅11次引用、JIF缺失，仍按直接酶学列核心暂定。指标为查询时快照，不代表未来数值。

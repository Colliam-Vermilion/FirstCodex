# 科学首页的文献关系与证据边界

本页说明2026-10-29科学首页怎样利用已有材料，不是新一轮检索或范围筛选。面向科研读者的正文在[仓库首页](../README.md)；原方法和运行介绍完整保留在[技术说明](../technical/README.md)，另有[逐字节旧首页](../technical/root_README_original_20261029.txt)。

## 怎样使用文献—命题表

[Excel](scientific_reading_guide.xlsx)与[完整CSV](literature_proposition_map_utf8.csv)覆盖原1,536个文献ID。42篇文章逐项整理为93条文献—命题关联；同一篇可以在不同部分支持不同问题。它们包括正面证据、反例、背景和适用条件，既不是42篇新纳入文献，也不是最终核心清单。

其余1,494篇保留原筛选结论、原阅读深度及七类标签，只按旧标签给出四部分的概念导航，**命题ID留空，明确标为本轮未逐项建立命题**。不以规则映射代替阅读或新筛选。原文献总表、优先级、判断、分类、累计Excel、RIS、指标及进度没有写回或重置。

## 本轮实际阅读了什么

在原已核实相关全文的文章中，定向重核了以下6篇已有方法/结果段落，未宣称全文通读或新增6篇全文核实：

- Khademian与Imlay（2020）：PFOR的直接分子氧损伤，以及“修复不了”的菌株/靶点边界。
- Jasso-Chávez等（2015）：长期培养和首次空气暴露的差别、产甲烷结果与供氧方法。
- Guo等（2022）：先小剂量、后大剂量的瓶间暴露历程，以及近一年恢复的归属。
- Wilmoth等（2021）：泥炭浆液、98天定期补气后134天厌氧；后期甲烷增强与解释层次。
- Broman等（2017，Frontiers）：完整柱芯，上覆水DO、毫米级氧穿透深度及类群变化。
- Lindsay等（2025）：采样柱芯不等于氧处理柱芯；提取稀释群落、氧量表述和呼吸代理/转录的差异。

另外3篇复用既有全文证据（Wu等2021、Duarte等2020、In 't Zandt等2018），未重读其整篇原件。其他文章的科学说明仅基于已保存的完整摘要；本轮读了相关摘要，不更改旧表中的阅读状态。新增阅读只记在本目录，避免把旧“全池初筛”改写成已全文核实。

## 尚不能得出的结论

不能给出通用安全DO、最适氧负荷或恢复时间；不能把土壤氧脉冲结果直接用于消化器，也不能从共现网络证明互作或DIET。长丝、聚集和生物膜的保护解释需局部氧与功能对照。自然环境中的干湿、水位、盐度、温度、底物和铁硫反应常与氧变化并行，需明确归因边界。

已建立的是可读的科学问题与文献关系，尚未对其余候选开展新的命题级阅读，也没有完成每项主张的独立验证。有关天然体系的说明覆盖本轮列出的材料，不是对全部库做完再次筛选后的穷尽清单。库中个别DOI/版本冲突仍按原记录保留，本轮不靠改写身份或判断来消除问题。

## 链接、保存与复现说明

原文/摘要入口均检查到仓库中实际存在的文件，DOI与作者/年份沿用现有记录；本轮没有重新请求出版商或把服务可访问性当作新增全文核实。科学首页与原文相对路径在独立GitHub检出中再检查。术语与外推说明是本轮编辑，原结果仍为来源。

`scripts/curate_records.py`保存本轮科学说明；`build_guide.py`只读取原材料并生成本目录的表格/证据卡；`write_homepage.py`生成科学首页。它们不执行数据库查询，也不写旧结果目录。若只需检查，用：

```bash
python scientific_guide/scripts/validate_guide.py
```

早期迁移检查绑定当时清单；当前检出存在科学首页检查时，迁移命令转至上述检查，防止把新说明误判为篡改旧结果。[本轮统计](summary.json)与后续`validation.json`、`remote_readback.json`记录本次编辑及独立读回。
